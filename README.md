# Light sheet fluorescent microscopy and automated 3D image analysis for quantitative lineage tracing in mouse cornea
This repo contains code used for processing of light sheet microscopy images of mouse cornea for Confetti lineage tracing analysis

## Abstract
Light sheet fluorescent microscopy (LSFM) can be used to obtain large-scale (up to whole organ) 3D-images while once one turns to lineage tracing there is a conflict between efficacy of tissue clearing, permeabilization for immunolabelling, and tracing signal salvation. 
We report a methodological and analytical pipeline that would aid researchers using multi-color (Confetti) lineage tracing and utilize LSFM along with immunolabeling procedures. We used mouse cornea as a primary object and provided its detailed characteristics at a cellular level using dual-view inverted selective plane illumination (diSPIM) microscopy. We developed a protocol for 3D image acquisition and analysis pipeline of lineage tracing data in Prrx1-expressing cells of corneal stromal and endothelial compartments. Morphometry data included calculation of cell number in epithelium, stroma, and endothelium along with measurement of corneal thickness and radius of curvature. The developed image analysis pipeline allowed calculation of Confetti markers distribution and quantitative clonal expansion estimation with adjustment imposed to correct spectral Confetti channel leakages. 
We believe that the presented methodology and 3D image analysis scripts should facilitate the lineage tracing studies and may be adapted to other organs.

## Description
All custom ImageJ scripts used for image analysis are present in `ImageJ_scripts` folder:
1) `Stitcher.ijm` Use BigStitcher plagin to stitch separate tiles and register two angles generated by light sheet microscopy
2) `Corneal_segmentation.ijm` For segmentation of cornea to epithelium, stroma, and endothelium performed using nuclei channel image
3) `Total_nuceli_counter.ijm` Takes segmented images of corneal epithelial, stromal and endothelial nuclei and calculates the number of nuclei in respective compartments using 3D ImageJ Suite plugin.
4) `Prrx1_nuclei_counter.ijm` Takes segmented images of corneal epithelial, stromal and endothelial nuclei along with GFP channel image and calculates the number of Prrx1-GFP-positive nuclei in respective compartments using 3D ImageJ Suite plugin.
5) `Leakage_calculation_from_GFP.ijm` Calculates the leakages from GFP using Confetti channels images
6) `Leakage_calculation_from_YFP.ijm` Calculates the leakages from YFP using Confetti channels images
7) `Confetti_correction.ijm` Correct the Confetti channel images for leakages calculated previously
8) `Confetti_nuclei_counter.ijm` Takes segmented images of corneal epithelial, stromal and endothelial nuclei along with Confetti channel images and calculates the number of Confetti-positive nuclei in respective compartments using MorphoLibJ plugin.

Jupyter Notebook `Clonal_expansion.ipynb` calculates clonal expansion metric based on nuclei coordinates and the information about their Confetti color or its absence
